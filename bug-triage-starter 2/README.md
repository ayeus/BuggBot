# AI-Powered Bug Reproduction & Triage — Starter

Opinionated FastAPI + minimal Next.js-ready layout. Use this as a baseline during the MVP phase.

## Quickstart (dev)
1) Create `.env` from `.env.example` and set values.
2) `docker compose up --build` (first run builds containers).
3) Open API docs at http://localhost:8000/docs

> The web app is scaffolded as `web/` with minimal placeholders. You can replace it with a full Next.js app.
