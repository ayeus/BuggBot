
# BuggBit Web (Next.js + Tailwind)

Run `npm create next-app@latest` here later, or integrate with existing Next.js app.
This folder will include:
- pages/: Submit Report, Triage Result, Artifacts, Integrations
- components/: Forms, Cards, Tabs
- lib/api.ts: Client for FastAPI endpoints
- auth: NextAuth (GitHub OAuth) or simple JWT
